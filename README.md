# Property Management System Client

The Property Management System Client is a comprehensive platform designed to streamline the management of reservations, housekeeping tasks, reports, payment processing, and more.

It offers a user-friendly interface for customers to book services and a powerful administrative dashboard for managing reservations, assigning housekeeping tasks, and handling payments efficiently and overall managing the property.

Its purpose is to improve operational efficiency and provide an exceptional user experience for both staff and administrators.

## Getting Started

For NextJS 14 a minimum of Node version `18.17.0` or higher is needed. The project is currently using verision `20.14.0`.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/example/pms-client.git
cd pms-client
```

2. Install dependencies:

```bash
npm install
```

## Running the Application

3. Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
